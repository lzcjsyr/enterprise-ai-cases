Round One:
Make it work first.

For the first version, focus oncomplete features and reliable logicwith a clear, simple interface. Send this prompt to the AI:

Read Annual Party Raffle List.xlsx in the project root and create an annual party raffle webpage saved as annual-raffle.html that opens directly in a browser. Requirements: 1. Read the participant list from Excel and embed the eligible names directly in the HTML; do not add an upload step. 2. Expect the columns “Name,” “Department,” and “Participating”; exclude anyone marked “No.” 3. Include “Start Drawing,” “Stop,” “Reset,” and “Export Winners” controls. 4. Scroll names during the drawing; when stopped, show the winner’s name and department. 5. Do not select a winner more than once. 6. Keep results on the current page; no server is needed. 7. Export winners to an Excel file and remind users to export before refreshing or closing the page. First make the features complete and reliable, with a clear, simple interface. When done, provide the file path and check that the HTML opens directly.
Remember the prompt structure:What to read → requirements → acceptance checksThis outline works for other cases too.
