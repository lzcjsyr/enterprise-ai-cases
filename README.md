# Enterprise AI Cases

Hands-on AI training through practical workplace scenarios across business functions.

This learner edition includes case briefs, sample data, and supporting materials. Answer keys are not included.

## Getting started

Choose a case, read its `Exercise.md` or `Case Walkthrough.html`, then use the supplied materials to complete the task. Not every case uses the same format.
